# ADR-014: Separate `config_schema_version` and `results_schema_version`

**Status:** Accepted (user decision 2026-10-13)

## Context

Config and result records evolve independently; committed example runs must stay readable.

## Alternatives considered

One shared `schema_version`.

## Decision

Two independently incremented counters; each reader rejects an unknown value of its own counter; golden-file tests cover both.

## Consequences / trade-offs

Two counters to maintain.
