# ADR-004: One fresh subprocess per trial; timing inside the worker; start-up reported separately

**Status:** Accepted

## Context

Clean per-trial memory counters, no state leakage between trials.

## Alternatives considered

In-process loop; wrapping pyperf.

## Decision

Every warm-up and measured trial runs `python -m sdplab.worker`; `perf_counter_ns` differences are taken inside the worker; the parent records `subprocess_wall_ns` separately and never adds it to operation timings.

## Consequences / trade-offs

More code and slower runs; the runner/worker protocol needs contract and fault-injection tests.
