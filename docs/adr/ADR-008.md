# ADR-008: Raw results as JSONL + run.json; derived, regenerable summary.csv

**Status:** Accepted (user decision 2026-10-13)

## Context

Each trial must be independently parseable and failures preserved.

## Alternatives considered

CSV only; SQLite.

## Decision

`results/raw/<run_id>/{run.json, trials.jsonl, summary.csv}`. `summary.csv` and plots are regenerable from raw files alone (`sdplab report --run <dir>`).

## Consequences / trade-offs

Append-safe; needs a flatten step for spreadsheets; truncated final line handling must be defined (RES-03).
