# ADR-016: Initial config key set includes `timeout_s`, noise thresholds, thread-env control; documented exit codes; example config

**Status:** Accepted (user decision 2026-10-13)

## Context

Unknown keys fail fast, so the full key set must exist from Phase 1; thresholds must be explicit and auditable; every raw observation is preserved.

## Alternatives considered

Add keys later.

## Decision

`[trials] timeout_s`; `[noise] outlier_factor, max_load_per_core`; `[environment] thread_env = inherit|single`; thread variables always recorded; exit codes 0-5 documented and tested; `configs/example.toml` ships and is validated by a test. Noisy trials are flagged, never discarded.

## Consequences / trade-offs

Slightly larger Phase 1 schema.
