# ADR-011: Narrow gitignore; curated example runs are tracked

**Status:** Accepted (user decision 2026-10-13; wording updated 2026-10-15 when the former planning framework was removed)

## Context

The repository must not carry machine-specific state or large generated data, but must keep a small curated example run so documentation numbers stay traceable.

## Alternatives considered

Ignore `data/` and `results/` wholesale.

## Decision

Ignore local Claude Code settings (`.claude/settings.local.json`), caches, `.venv/`, `data/generated/` and `results/raw|plots|reports/` (with `.gitkeep` exceptions). `results/examples/` is tracked for curated runs.

## Consequences / trade-offs

The example run must be curated deliberately (`sdplab report --run ... --example-dir results/examples`).
