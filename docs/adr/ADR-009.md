# ADR-009: argparse + TOML (`tomllib`)

**Status:** Accepted

## Context

Five small subcommands; standard-library only.

## Alternatives considered

Typer/Click; YAML.

## Decision

`argparse` CLI; config read with `tomllib` and validated by hand (types, ranges, unknown keys).

## Consequences / trade-offs

Plainer help text; hand-written validation.
