# ADR-003: MVP variants: csv, npy, npz, npz_compressed

**Status:** Accepted

## Context

Smallest set answering RQ1-RQ5.

## Alternatives considered

Add JSON/HDF5/Parquet/ROOT now; include column-wise npz.

## Decision

Four variants. Others are optional extensions after the baseline is correct.

## Consequences / trade-offs

Fewer insights on layout; faster path to a correct baseline.
