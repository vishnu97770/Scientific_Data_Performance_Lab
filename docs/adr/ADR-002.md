# ADR-002: Canonical in-memory form is one structured array (`EVENT_DTYPE`)

**Status:** Accepted (user decision 2026-10-13)

## Context

Format comparison must hold the logical schema and record layout constant.

## Alternatives considered

dict of columns; pandas DataFrame; per-column files.

## Decision

All four variants store and return the same 1-D C-contiguous, packed, little-endian structured array (`<i8, <f8, <f8, <f8, <i2`; 34 B/row). Column-wise `.npz` is deferred as a separate storage-layout study.

## Consequences / trade-offs

Format-only comparison; row-wise layout forgoes columnar benefits. Dataset identity hash covers dtype description, shape and bytes.
