# ADR-010: Median/IQR headline; no significance tests

**Status:** Accepted

## Context

Robust on noisy laptop hardware (pyperf analysis docs).

## Alternatives considered

mean+-std; t-tests; bootstrap.

## Decision

Per cell: n_ok, n_failed, n_incorrect, median (headline), Q1, Q3, IQR (quantile method named), min, max, mean, stdev. Ratios use medians. No significance claims.

## Consequences / trade-offs

Less statistical power; honest about what is measured.
