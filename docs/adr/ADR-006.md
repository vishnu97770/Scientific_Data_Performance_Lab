# ADR-006: Warm-cache benchmark only

**Status:** Accepted

## Context

Cold-cache needs system-wide privileged operations (kernel docs: use outside testing/debugging is not recommended).

## Alternatives considered

drop_caches; O_DIRECT; fadvise.

## Decision

Every trial records `cache_mode = "warm"`. A process restart is never described as clearing the OS page cache. Cold-cache is an optional future extension.

## Consequences / trade-offs

Portable and honest; not a device-throughput study.
