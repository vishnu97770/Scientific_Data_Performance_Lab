# ADR-015: Python >= 3.12; primary 3.13; CI tests 3.12 and 3.13

**Status:** Accepted (user decision 2026-10-13)

## Context

The latest NumPy (2.5.x) requires Python >= 3.12; claiming 3.11 would require an older NumPy.

## Alternatives considered

Keep 3.11 with NumPy 2.4; pin `numpy<2.5`.

## Decision

`requires-python = ">=3.12"`. A throwaway `uv lock` resolved a single NumPy 2.5.4 (research-notes 7.2); the real lock is verified in Phase 1, with a lowest-direct check or raised floors. No claim of 3.11 support.

## Consequences / trade-offs

Excludes 3.11 users.
