# ADR-017: Per-operation correctness validation

**Status:** Accepted (user decision 2026-10-13)

## Context

An unchecked write or preprocess result could silently be wrong.

## Alternatives considered

Validate load only.

## Decision

Every operation records `correct` and `correctness_check` (`load` hash; `preprocess` digest; `load_preprocess` both; `write` read-back by an untimed reference loader; `not_applicable` explicit). Checks run after the timer and after memory counters are read. Worker input and expected-value passing are decided in Phase 3 planning.

## Consequences / trade-offs

More worker logic; deferred design questions recorded in the roadmap.
