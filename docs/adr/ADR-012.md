# ADR-012: Default write timing excludes fsync

**Status:** Accepted

## Context

Reproducibility and less device noise.

## Alternatives considered

Always fsync.

## Decision

Default `write` timing ends at file close and may include OS buffering; it is not the time to persist data to the device. An optional `--fsync` experiment is a separate, labelled operation (optional extension).

## Consequences / trade-offs

Not persistence time.
