# ADR-001: One flat package `sdplab`

**Status:** Accepted (2026-10-13)

## Context

One developer, four variants, roughly ten responsibilities.

## Alternatives considered

Several sub-packages; an ABC/plugin system for formats.

## Decision

One installable package `sdplab` with ~10 flat modules (`config, dataset, formats, preprocess, validate, worker, runner, results, analysis, report, cli`). No abstract base classes; `formats.py` is a deep module with a two-function interface per variant and a registry. Dependency rules are in PROPOSAL section 6.

## Consequences / trade-offs

Interface depth over module count; adding a format edits `formats.py` or splits it later. Timing/memory measurement lives inside `worker.py`.
